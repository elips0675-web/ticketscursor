## Текущие проблемы (нужно исправить)

### 🔴 КРИТИЧНО (P0 — ломает CI/Docker/прод)

| # | Проблема | Факт | Решение | Время |
|---|----------|------|---------|-------|
| 1 | **CI: `cmd /c` на Ubuntu** | `.github/workflows/ci.yml` — `cmd /c "npx vitest run"` не работает на ubuntu-latest | Заменить на `working-directory: server` + `npx vitest run` | 5 мин |
| 2 | **Docker: неправильный stage** | `docker-compose.yml` — `build: .` без `target` → соберёт nginx вместо node | Добавить `build: { context: ., target: server }` | 10 мин |
| 3 | **check-bundle-size.js: require в ESM** | Файл с `import` использует `require('zlib')` → ReferenceError, catch молча глотает | Заменить на `import { gzipSync } from 'node:zlib'` | 5 мин |
| 4 | **entrypoint.sh: не скопирован** | Dockerfile не содержит `COPY docker/entrypoint.sh` + `ENTRYPOINT` | Добавить COPY + ENTRYPOINT | 5 мин |
| 5 | **Docker: Playwright job без сервера** | CI playwright job не устанавливает зависимости сервера, запускает `node src/index.js` без wait-on | Добавить `npm ci` в server deps + `wait-on http://localhost:4000` | 15 мин |
