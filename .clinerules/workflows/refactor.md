# /refactor — один файл, без изменения поведения

## Когда

Нужно упростить участок, сохранив поведение и тесты.

## Шаги

1. Запусти тесты участка до правки и зафиксируй результат:
   `npm test -- <тест>`.
2. Прочитай файл целиком; назови, что именно упрощаем и зачем (одна причина).
3. План из 1–3 шагов, без изменения публичного контракта и текстов ошибок.
4. Делай по одному шагу, после каждого — тесты участка.
5. Если поведение изменилось — откати шаг и объясни почему.
6. `npm run stage:gates` → всё из «ИТОГО».
7. Отчёт: что упрощено, тесты до/после, что не проверено.

## Стоп

- Нет тестов на участок → сначала `/test.md`, потом рефакторинг.
- Файл больше 500 строк или правка затрагивает > 3 файлов → сузить или
  согласовать отдельный этап.

## Запреты

- Не менять API, схему БД, i18n-ключи и тексты ошибок без отдельного решения.
- Не смешивать рефакторинг и новую функциональность в одном шаге.
- Не трогать форматирование всего файла, если правится одна функция.
