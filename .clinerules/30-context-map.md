Твой контекст — 16 384 токена на всё: правила + история чата + прочитанные файлы. Не читай проект целиком.

## Порядок чтения

1. `npm run stage:context` — вместо трёх журналов.
2. Пункт задачи в `Что-доделать.txt` — `grep` по ID (`P1-14`), не читай файл (85 КБ).
3. Целевой файл кода — только нужные функции: `grep -n` по имени символа, затем чтение диапазона.
4. Существующие тесты рядом (`src/test/<Component>*.test.tsx`) — как образец стиля и моков (MSW).
