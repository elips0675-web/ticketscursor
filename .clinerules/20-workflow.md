# 20 — Рабочий процесс (строго)

## Старт сессии

1. `npm run stage:context` — git-статус, счётчики тестов, открытые этапы, хвост «Что сделано.txt». Одна команда вместо чтения трёх журналов.
2. Убедись, что выбранный пункт есть в `Что-доделать.txt` и он открыт (`⏳`). Если пункта нет — стоп, спроси пользователя.
3. Прочитай только релевантные файлы (см. `30-context-map.md`), не весь проект.

## Цикл правки

1. Найди факты: `file:line`, существующие типы, похожие тесты.
2. Минимальный дифф: правь только то, что требует задача. Стиль — как в соседнем коде.
3. Негативные сценарии обязательны (правило 17): без прав → 403; просроченный токен → 401; невалидное тело → 400; повторная отправка → нет дубля; недоступный Redis/SMTP/S3 → деградация, а не 500.
4. Идемпотентность: outbox / очереди / retry / DLQ / WS / таймеры — повторная обработка не создаёт дублей.
5. Изменение схемы БД = миграционный пакет (правило 18): идемпотентная миграция Knex, обновление `schema.prisma` + `prisma generate`, seed, индексы, обратная совместимость.
6. Новый публичный экран = фича-флаг + тест + i18n (ru/en) + `check-console` + инвентарь (правило 13, DoD).

## Финиш

1. `npm run stage:gates` → выполнить всё, что он напечатал в «ИТОГО».
2. Если менял `.md`/`.txt` — синхронизировать зеркало в `test-analysis/` (побайтово) и прогнать `npm run check:docs`.
3. Если менял тесты — перегенерировать `test-analysis/test-inventory.json` и `frontend-tests.txt`/`server-tests.txt` (правило 10).
4. Отчёт: что сделано, `file:line`, вывод гейтов, что осталось.

## Журналы и бэклог

- Бэклог = только открытые вопросы. Закрытый пункт — одна компактная строка `✅` + ссылка на «Что сделано.txt»; «надгробия» (секция ЗАКРЫТО с телом) = FAIL (правило 20).
- Историю и прошлые срезы — в `Что сделано.txt` и `CHANGELOG-archive.md`.
- Правки журналов — только node-скриптами, затем `node scripts/check-doc-sync.mjs`.

## Формат ответа пользователю

- По-русски, коротко.
- Список файлов и сути правок, ссылки `file:line`.
- Итоги гейтов (exit 0 / строка `ALL OK`).
- Явно: что НЕ сделано и почему (если остались blockers).
